# Замер скорости скачивания

Скрипт измеряет скорость скачивания с конкретного URL. Он делает 10 GET-запросов подряд: следующий начинается только после того, как предыдущий ответ прочитан целиком. Данные читаются кусками и не сохраняются на диск.

## Запуск

Нужен Python 3.9 или новее, устанавливать библиотеки не нужно:

```sh
git clone https://github.com/nolletinfluence/internet-download-speed.git
cd internet-download-speed
python3 speed_test.py 'https://www.python.org/ftp/python/doc/3.13.0/python-3.13.0-docs-text.tar.bz2'
```

В примере используется архив документации Python размером около 3 МБ. За 10 запросов скрипт скачает около 30 МБ. Можно подставить прямую ссылку на свой файл. На маленьком файле задержка соединения может занять большую часть времени. HTTP-переадресации обрабатываются автоматически.

## Что означают результаты

- **Среднее время запроса** — сумма времени десяти загрузок, делённая на 10, в секундах. Замер начинается перед отправкой запроса и заканчивается после чтения тела ответа.
- **Всего скачано** — сумма фактически прочитанных байтов тел ответов, без HTTP-заголовков.
- **Скорость скачивания** — общий объём в битах, делённый на суммарное время, в **Мбит/с** (`1 Мбит/с = 1 000 000 бит/с`, `1 байт = 8 бит`).

Результат зависит от сервера, сети до него и самого файла. При ошибке скрипт указывает номер запроса и завершает замер с кодом `1`; неполный результат не выводится. Таймаут сетевой операции — 15 секунд.

## Тесты

```sh
python3 -m unittest -v
```

Тесты используют локальный HTTP-сервер и проверяют порядок десяти загрузок и остановку при обрыве ответа. Доступ в интернет для тестов не нужен.
